# ai-uxr-tools
AI用研工具榜：中文用研人的 AI 工具库与评测

线上：https://huangzhenhao90.github.io/ai-uxr-tools/ · 姊妹站 [UXHOT · AI 用研热点](https://huangzhenhao90.github.io/ai-ux-research-hot/) · 真知浩见出品

- Next.js 15 静态导出（basePath `/ai-uxr-tools`），推送 `main` 后由 `.github/workflows/deploy.yml` 部署到 GitHub Pages。
- 数据：`data/tools.json`（站点使用）与 `data/tools.csv`，共 54 个工具、7 个分类。
- 本地：`npm ci && npm run dev`；构建：`npm run build`（产物在 `out/`）。
- 收录、纠错与合作：公众号「真知浩见」后台留言。
